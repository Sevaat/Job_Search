# Проект: Парсер вакансий с hh.ru + БД PostgreSQL

**Цель проекта**:  
Получить данные о работодателях и вакансиях с сайта **hh.ru** через публичный API, сохранить их в **PostgreSQL**, и реализовать удобный доступ к данным через класс `DBManager`.

---

## Особенности проекта

- **API hh.ru** — сбор данных без авторизации
- **PostgreSQL** — надёжное хранение с внешними ключами
- **psycopg2** — работа с БД
- **Класс `DBManager`** — 5 методов для аналитики
- **Безопасное хранение пароля** — через `.env`
- **Автообновление данных** (без дубликатов)

---

## Установка

В проекте используется виртуальное окружение Poetry. Для корректной работы необходимо установить Poetry, включить виртуальное окружение.  
Для установки всех зависимостей необходимо в терминале ввести команду:  

```
poetry install
```

Основные зависимости:  
python = "^3.12" - Python версии 3.12 или выше  
psycopg2-binary = "^2.9.11" - пакеты для работы с БД

## Класс DBManager — аналитика

Метод - Описание  
get_companies_and_vacancies_count() - Топ компаний по количеству вакансий  
get_all_vacancies() - Все вакансии с зарплатой и ссылкой  
get_avg_salary() - Средняя зарплата по всем вакансиям  
get_vacancies_with_higher_salary() - Вакансии с зарплатой выше средней  
"get_vacancies_with_keyword(""python"")" - Поиск по ключевому слову  

## Структура БД

### Таблица companies

Поле - Тип - Описание  
company_id - INTEGER PRIMARY KEY - ID на hh.ru  
name - VARCHAR(255) - Название  
url - TEXT - Ссылка на hh.ru  
description - TEXT - Описание  
site_url - TEXT - Официальный сайт  

### Таблица vacancies

Поле - Тип - Описание  
vacancy_id - INTEGER PRIMARY KEY - ID вакансии  
company_id - INTEGER FK → companies - Внешний ключ  
name - VARCHAR(255) - Название  
salary_from / salary_to - INTEGER - Зарплата  
currency - VARCHAR(10) - "RUR, USD"  
url - TEXT - Ссылка на hh.ru  
area - VARCHAR(100) - Город  
published_at - TIMESTAMP - Дата
